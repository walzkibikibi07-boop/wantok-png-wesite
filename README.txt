WANTOK PNG stylish website with official logo

Files: index.html, wantok-png-logo.png, README.txt. Keep index.html and wantok-png-logo.png in the same folder when publishing. The logo appears in the website header and footer.

This is a static visual website starter. Example business cards are placeholders. The enquiry form does not send or store data. Accounts, database-backed listings, payments, delivery booking, secure acquittal uploads and official Treasury integration require additional development and approvals.

Free publishing option: create a public GitHub repository, upload index.html and wantok-png-logo.png to its root, then go to Settings > Pages and select deploy from branch main and folder /(root). Save and wait for the public site address.
